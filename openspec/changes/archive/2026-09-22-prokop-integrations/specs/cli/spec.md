## ADDED Requirements

### Requirement: Подкоманда `memory`

CLI SHALL предоставлять подкоманду `memory` с операциями: перечисление
сохранённых фактов, поиск по памяти и удаление факта по ключу. Подкоманда
MUST быть локальной: она MUST NOT требовать ключа модели и MUST NOT
обращаться к сети. Удаление несуществующего ключа MUST NOT приводить к ошибке.

#### Scenario: Перечисление фактов

- **WHEN** выполнено `prokop memory list`
- **THEN** выводятся сохранённые факты профиля и код возврата равен `0`

#### Scenario: Пустая память

- **WHEN** память пуста
- **THEN** выводится сообщение об отсутствии фактов и код возврата равен `0`

#### Scenario: Поиск по памяти

- **WHEN** выполнено `prokop memory search <запрос>`
- **THEN** выводятся совпавшие записи и код возврата равен `0`

#### Scenario: Удаление факта

- **WHEN** выполнено `prokop memory forget <ключ>`
- **THEN** факт удаляется и код возврата равен `0`

#### Scenario: Удаление несуществующего ключа

- **WHEN** указан ключ, которого нет в памяти
- **THEN** сообщается, что факт не найден, и код возврата равен `0`

#### Scenario: Провайдер памяти не файловый

- **WHEN** в конфигурации профиля выбран провайдер, не поддерживающий
  перечисление фактов
- **THEN** выводится сообщение об этом и код возврата равен `0`
