## ADDED Requirements

### Requirement: Разрешение провайдера памяти по конфигурации

Ядро SHALL разрешать имя провайдера из `memory.provider` конфигурации профиля
в реализацию и SHALL подключать её к менеджеру памяти как внешний провайдер.
Имя `builtin` (или отсутствие настройки) MUST означать отсутствие внешнего
провайдера. Неизвестное имя MUST давать предупреждение и MUST NOT прерывать
работу: используется встроенная память.

#### Scenario: Провайдер не задан

- **WHEN** в конфигурации профиля нет `memory.provider`
- **THEN** менеджер памяти работает только со встроенным провайдером

#### Scenario: Встроенный провайдер указан явно

- **WHEN** в конфигурации указан `memory.provider: builtin`
- **THEN** внешний провайдер не подключается

#### Scenario: Файловый провайдер подключён

- **WHEN** в конфигурации указан `memory.provider: file`
- **THEN** менеджер получает внешний файловый провайдер, а список активных
  провайдеров содержит встроенный первым

#### Scenario: Неизвестное имя провайдера

- **WHEN** в конфигурации указано имя, которого нет в реестре провайдеров
- **THEN** выводится предупреждение, внешний провайдер не подключается, работа
  продолжается на встроенной памяти

### Requirement: Файловый провайдер памяти

Файловый провайдер SHALL хранить постоянные факты и дайджесты завершённых
ходов в домашнем каталоге профиля и SHALL переживать перезапуск процесса.
Хранилище MUST быть формата «одна запись на строку» (JSONL) и MUST
дописываться без перезаписи существующих записей. Провайдер MUST быть
устойчив к повреждённому хранилищу: битые строки пропускаются, а не приводят
к отказу памяти.

#### Scenario: Факт переживает перезапуск

- **WHEN** факт сохранён, процесс завершён и создан новый экземпляр провайдера
- **THEN** сохранённый факт доступен новому экземпляру

#### Scenario: Дайджест хода сохраняется

- **WHEN** завершён ход агента и вызвана синхронизация хода
- **THEN** в хранилище появляется запись хода с текстом запроса и ответа

#### Scenario: Повреждённая строка хранилища

- **WHEN** в файле хранилища есть строка, не являющаяся валидным JSON
- **THEN** она пропускается, остальные записи читаются

#### Scenario: Отсутствующее хранилище

- **WHEN** файл хранилища ещё не создан
- **THEN** память пуста и обращение к ней не приводит к ошибке

### Requirement: Релевантная подгрузка памяти

Провайдер SHALL подбирать записи памяти по запросу хода: оценка MUST
основываться на пересечении токенов запроса и текста записи, регистр MUST NOT
учитываться, поддержка кириллицы обязательна. Подбор MUST возвращать
ограниченное число записей и MUST NOT требовать внешних сервисов. Пустой
запрос MUST возвращать самые свежие факты.

#### Scenario: Запрос совпадает с фактом

- **WHEN** запрос содержит слова из сохранённого факта
- **THEN** этот факт попадает в подгружаемый контекст

#### Scenario: Нерелевантные записи не подгружаются

- **WHEN** запрос не пересекается ни с одной записью
- **THEN** подгружаемый контекст пуст

#### Scenario: Кириллица в запросе

- **WHEN** запрос и факт записаны кириллицей
- **THEN** факт находится по совпадению слов

#### Scenario: Ограничение числа записей

- **WHEN** релевантных записей больше предела подгрузки
- **THEN** возвращается не более предела, начиная с наиболее релевантных

### Requirement: Инструменты файловой памяти

Провайдер SHALL предоставлять агенту инструменты сохранения факта, поиска по
памяти и удаления факта. Инструменты MUST возвращать результат в формате ядра
(JSON-строка) и MUST NOT бросать исключения наружу: ошибка возвращается как
результат.

#### Scenario: Сохранение факта инструментом

- **WHEN** агент вызывает инструмент сохранения с ключом и значением
- **THEN** факт сохранён и доступен поиску

#### Scenario: Поиск по памяти инструментом

- **WHEN** агент вызывает инструмент поиска с запросом
- **THEN** возвращаются совпавшие записи

#### Scenario: Удаление факта инструментом

- **WHEN** агент вызывает инструмент удаления с существующим ключом
- **THEN** факт перестаёт находиться поиском

#### Scenario: Отсутствие обязательного аргумента

- **WHEN** инструмент вызван без обязательного аргумента
- **THEN** возвращается результат с ошибкой, исключение не поднимается

### Requirement: Ограничение объёма памяти

Провайдер SHALL ограничивать число хранимых записей: при превышении предела
хранилище MUST перезаписываться с сохранением самых свежих записей, а
перезапись MUST быть атомарной. Провайдер SHALL сообщать пути хранилища для
резервного копирования.

#### Scenario: Превышение предела записей

- **WHEN** число записей превышает предел
- **THEN** хранилище содержит не более предела самых свежих записей

#### Scenario: Пути для резервного копирования

- **WHEN** запрошены пути резервного копирования
- **THEN** возвращается путь хранилища памяти профиля
