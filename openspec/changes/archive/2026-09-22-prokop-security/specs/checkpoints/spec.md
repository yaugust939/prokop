## ADDED Requirements

### Requirement: Проверка политики путей при работе со снимками

Операции со снимками SHALL проверять политику путей перед изменением файлов
(создание снимка и восстановление) и MUST NOT изменять путь, для которого
политика вынесла запрет. Отчёт MUST содержать причину пропуска.

#### Scenario: Запрещённый путь при восстановлении

- **WHEN** путь восстановления совпадает с запрещающим шаблоном политики
- **THEN** файл по этому пути не изменяется, а причина попадает в отчёт

#### Scenario: Запрещённый путь при создании снимка

- **WHEN** указанный для снимка путь совпадает с запрещающим шаблоном политики
- **THEN** содержимое этого пути в снимок не попадает

#### Scenario: Путь без запретов

- **WHEN** для пути нет запрещающих правил политики
- **THEN** операция выполняется как обычно
