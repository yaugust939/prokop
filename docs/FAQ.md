# prokop — FAQ

Частые вопросы о проекте **prokop** (универсальное ядро агента).

## Общие

**Что такое prokop?**
Открытое универсальное ядро для построения автономных агентов: цикл исполнения,
инструменты, память, планировщик, делегирование и исполнение команд — плюс интеграция
с opencode. Поставляется как Python-пакет, Docker-образ и MCP-сервер.

**Чем отличается от других агентных фреймворков?**
Даёт ядро **и обвес** сразу (цикл, инструменты, память, планировщик, субагенты,
бэкенды, гейтвей), не привязан к модели (провайдер меняется настройкой), проверен
173 тестами и чистой установкой в контейнере, открыт под MIT.

**Это бесплатно? Какая лицензия?**
Да, открытый код под лицензией **MIT** — используйте, меняйте, включайте в свои проекты.

**Это «ещё одна обёртка над чатом»?**
Нет. Это ядро агента, которое реально исполняет: вызывает инструменты, хранит память,
планирует задания, делегирует подзадачи и выполняет команды — а не только генерирует текст.

## Установка и запуск

**Какой нужен Python?**
Python **3.11+**.

**Как установить?**
```bash
git clone https://github.com/yaugust939/prokop.git
cd prokop
pip install -e src
```
Или контейнером: `docker build -t prokop:clean .`.

**Нужен ли API-ключ?**
Для живых ходов — да, ключ модельного провайдера (по умолчанию DeepSeek). Задайте
`DEEPSEEK_API_KEY` или положите в `src/.env`. Без ключа работают тесты и «сухие» сценарии.

**Как проверить, что установка рабочая?**
```bash
python -c "import prokop; print(prokop.__version__)"
cd src && python -m pytest tests -q      # 173 теста
```

## Модели и провайдеры

**Какие модели поддерживаются?**
Любые через слой провайдеров. По умолчанию — DeepSeek (`deepseek-chat`). Профиль
провайдера задаёт режим API, базовый URL и переменные ключа.

**Можно ли сменить модель без правки кода?**
Да — это одно из ключевых свойств: модель/провайдер переключаются настройкой,
код не меняется.

**Можно ли подключить локальную модель (например, Ollama)?**
Архитектура провайдеров это позволяет (встроенный профиль `ollama`); укажите
`base_url` локального сервера и модель.

## Использование

**Как пользоваться через opencode?**
MCP-сервер `prokop` даёт инструменты `prokop_agent_turn`, `prokop_agent_schedule_job`,
`prokop_agent_list_jobs`, `prokop_agent_run_ticker`, `prokop_agent_run_command`.
В переключателе агентов есть агент **prokop**. После правки конфига перезапустите opencode.

**Что такое `SOUL.md`?**
Каноническая личность агента `prokop` (характер, ценности, стиль, границы). Источник
идентичности; технические правила исполнения — в конфиге агента.

**Можно ли добавить свои инструменты?**
Да — инструменты регистрируются декларативно через `prokop.tools.register(...)`.

**Где хранятся данные (сессии, задания)?**
В домашнем каталоге профиля — по умолчанию `~/.prokop` (переопределяется `PROKOP_HOME`).

## Безопасность

**Куда кладутся секреты?**
Только в переменные окружения или `.env` (он в `.gitignore`). Секреты не пишутся в код,
логи и артефакты.

**Есть ли защита от опасных команд?**
Да: у инструментов есть разрешения и **жёсткий блок-лист** опасных команд
(рекурсивное удаление корня, `mkfs`, `dd` на блочные устройства, fork-бомба и т.п.),
не выполняемых даже в «свободном» режиме.

**Можно ли использовать в продакшене?**
Ядро проверено тестами и контейнерной установкой. Для продакшена добавьте свои практики
(управление секретами, мониторинг, лимиты). Статус версий — в `CHANGELOG.md`.
