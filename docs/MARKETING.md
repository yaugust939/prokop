## Позиционирование одной строкой

**prokop** — открытое универсальное ядро, из которого собираются агенты, реально
делающие работу: вызывают инструменты, помнят контекст, планируют задачи,
делегируют подзадачи и исполняют команды — с любой моделью и без привязки к вендору.

## Elevator pitch (30 секунд)

Большинство «агентов» — это обёртка над чатом. **prokop** — это ядро агента, который
работает: у него есть цикл «подумал → вызвал инструмент → получил результат → ответил»,
память между сессиями, планировщик отложенных задач, делегирование подзадач и исполнение
команд в изолированном окружении. Модель — любая: провайдер меняется одной настройкой,
без правки кода. Открытый код (MIT), ставится одной командой или контейнером,
подключается к opencode как готовый агент и MCP-инструменты.

## Проблема

Собрать агента «с нуля» — дорого и долго: нужно самому писать цикл исполнения,
реестр инструментов, память, безопасность вызовов, планировщик и интеграции.
Готовые фреймворки часто:

- привязывают к одному вендору/модели;
- тащат лишние зависимости и абстракции;
- не дают памяти, планировщика и делегирования «из коробки»;
- закрыты или обросли лицензионными ограничениями.

## Решение и ценность

**prokop** даёт готовое, проверенное тестами ядро и обвес, на котором агент
собирается за часы, а не недели:

| Боль | Что даёт prokop |
|---|---|
| Писать цикл агента с нуля | Готовый `loop`: модель → инструменты → модель, стриминг, ретраи, бюджеты |
| Безопасность инструментов | Декларативный реестр, разрешения, жёсткий блок-лист опасных команд |
| Нет памяти | Память + хранилище сессий (SQLite + полнотекстовый поиск) |
| Нет планировщика | `cron`: отложенные/периодические задания с доставкой |
| Нет параллельности | `subagents`: делегирование с изоляцией и бюджетами |
| Исполнение команд | Терминальные бэкенды (снимок окружения, обрезка вывода) |
| Привязка к вендору | Слой провайдеров: смена модели без правки кода |
| Долгая интеграция | Готовый MCP-сервер и агент для opencode |

## Целевая аудитория

1. **Разработчики ИИ-агентов** — хотят каркас, а не писать инфраструктуру.
2. **Инженеры автоматизации** — нужен агент для отложенных/фоновых задач и команд.
3. **Пользователи opencode** — хотят готового агента-помощника и MCP-инструменты.
4. **Те, кто ценит открытость** — MIT, свой хостинг, любая модель.

- **Для ценителей открытости:** «Открытое ядро агента, любая модель, без привязки к вендору. MIT».

## Отличия (why us)

- **Ядро + обвес сразу:** цикл, инструменты, память, планировщик, субагенты, бэкенды, гейтвей.
- **Провайдер-агностичность:** смена модели одной настройкой.
- **Проверено:** 173 юнит-тестов + чистая установка в контейнере (тесты в самой сборке).
- **Интеграция с opencode:** MCP-сервер `prokop` + агент `prokop` (универсальный помощник).
- **Простота установки:** `pip install -e src` или `docker build`.
- **Открытость:** MIT, без скрытых ограничений.
