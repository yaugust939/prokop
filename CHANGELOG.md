# Changelog

Все значимые изменения проекта документируются в этом файле.

Формат основан на [Keep a Changelog](https://keepachangelog.com/en/1.1.0/),
проект следует [семантическому версионированию](https://semver.org/lang/ru/).

## [0.1.0] — 2026-08-25

Первый публичный релиз: оригинальное ядро универсального агента, написанное
с нуля по поведенческой спецификации (чистая комната).

### Добавлено
- **Цикл агента** (`loop`): пролог → «модель → инструменты → модель» → финализация;
  прерывание / steer / redirect, стриминг, байт-стабильный системный промпт,
  бюджеты итераций и настенных часов, ретраи с классификацией ошибок, аренда сессии.
- **Инструменты** (`tools`): декларативный реестр, наборы с композицией,
  коэрция аргументов по схеме, разрешения и жёсткий блок-лист, прогрессивное раскрытие.
- **Навыки** (`skills`): структура навыка, доступ (список/просмотр/управление),
  создание и патч, куратор жизненного цикла (архив без удаления).
- **Память** (`memory`): контракт провайдеров, менеджер (встроенный первый,
  максимум один внешний), впрыск контекста в пользовательское сообщение.
- **Хранилище сессий** (`store`): SQLite + FTS5 (стандартный и триграммный индексы),
  поиск по сессиям с якорным окном и «букендами», экспорт/импорт.
- **Провайдеры моделей** (`providers`): декларативные профили, реестр с приоритетами,
  провайдер-агностичное переключение модели.
- **Планировщик** (`cron`): разбор расписаний, тикер, исполнение «без агента»,
  доставка, переживание перезапуска.
- **Субагенты** (`subagents`): делегирование, изоляция ребёнка, роли лист/оркестратор,
  бюджеты, асинхронный возврат сводки.
- **Терминальные бэкенды** (`backends`): контракт, снимок окружения, локальный бэкенд,
  обрезка вывода «голова+хвост» со свалкой.
- **Гейтвей** (`gateway`): ключ сессии, нормализованное событие, контракт адаптера,
  авторизация отправителя, защита от параллельных ходов, кэш агентов, подготовка ответа.
- **Интеграция с opencode** через MCP-сервер: `agent_turn`, `agent_schedule_job`,
  `agent_list_jobs`, `agent_run_ticker`, `agent_run_command`.
- **CI**: прогон тестов на Python 3.11 / 3.12 / 3.13.

### Примечание
- Чистая комната: код написан по поведенческой спецификации (см. `openspec/`),
  без копирования из какого-либо эталона. Провенанс — в `clean-room/`.
- 171 тест на момент релиза.
