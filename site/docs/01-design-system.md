## 1. Откуда взялась форма

Инженерная задача — ядро агента, поверх которого собирают своего агента. Культурная рамка — старообрядческая книга: верность канону, соборная работа, книга как первоклассный артефакт, лестовка как лестница ступеней, раскол как своя ветвь.

Соответствие не декоративное, а точное:

| Старообрядчество | Открытое ядро |
|---|---|
| Верность канону, отказ от реформы | Лицензия MIT и зафиксированные контракты в `openspec/` |
| Соборность, решение сообща | Ревью, форки, вклад сообщества |
| Книга, рукописная традиция | Документация как первоклассный артефакт |
| Лестовка — лестница ступеней | Тесты: ступени проверки |
| Раскол, своя ветвь | Форк — и буквально ветка `site` |

**Дисциплина, которая из этого следует.** Метафора живёт **в форме**: знак, палитра, шрифт, орнамент, названия секций. Копирайт остаётся техническим и проверяемым: ни одного церковнославянского обещания в тексте про продукт. Красивая форма при честном тексте — иначе получается тот самый «ИИ-банальный дизайн», за который забраковали восьмибитную версию сайта артели.

**Почему пиксель здесь не грех.** Пиксель в этом бренде — не игровая ностальгия, а **литера**: единица набора. Старопечатная книга сама модульна — литеры, заставки, киноварные пометы. Иван Фёдоров набирал страницу из многократно повторённых отлитых элементов; ровно то же делает модульный шрифт. Модуль как единица набора — общий язык книги и машины. И пиксель здесь не единственная стратегия: основную нагрузку несёт книжная акциденция, модульный слой — акцент.

## 2. Принципы

1. **Два акцента на экран.** Киноварь и ярь-медянка. Сусаль — цвет книги и наследия, а не третий акцент. Крутик — только ссылки и глубина.
2. **Форма из знака.** Модуль 8px, радиусы короткие, блочность. Пиксель живёт в знаке, надписи, метках и орнаменте — не в абзацах.
3. **Тёмная по умолчанию.** ЭЛТ-лампада: сажа, свечение, тёплая бумага вместо белого. Светлая тема — полный комплект, а не заглушка.
4. **Иерархия вместо декора.** Главное крупно, второстепенное мелко, контраст не ниже нормы.
5. **Честные данные.** Число тестов, статус возможности, вывод терминала — из сборки, не из головы.
6. **Читаемость прежде красоты.** Свечение и скан-линии только фоном, никогда под смысловым текстом.

## 3. Цвет

Палитра названа по пигментам старопечатной книги и меднолитой иконы. «Неон» — тот же пигмент, увиденный на ЭЛТ. Три тона на пигмент: **300** для тёмного фона, **500** основной для заливок, **700** для мелкого текста на бумаге.

| Имя | Тона | Роль |
|---|---|---|
| **Сажа** | `#0B0A09` `#141210` `#1D1A17` `#2A2622` `#3B3530` | фон и поверхности тёмной темы |
| **Поновление** | `#F4EDDD` `#E7DCC6` `#D3C4A8` | светлая тема: тёплая бумага, не белый |
| **Киноварь** | `#F2705C` `#D8382B` `#B02A20` | главный акцент: действие, буквица, печать |
| **Ярь-медянка** | `#57D9B4` `#2F9E82` `#1A6150` | второй акцент: данные, статусы, терминал |
| **Сусаль** | `#E0A75C` `#C8873C` `#7A4E14` | золото книги, наследие, «мастерство» |
| **Крутик** | `#6B8FE0` `#2B4C8C` | ссылки, глубина |
| **Медь** | `#C48A6A` `#9A5B3B` | тёплый нейтральный, линии |

### 3.1 Разделение заливки и текста — не прихоть

Средние тона не проходят норму 4.5:1 для мелкого текста ни на тёмном, ни на светлом фоне. Поэтому в семантических ролях заливка и текст разведены: `--accent` для графики, `--accent-text` для текста, `--accent-fill` для заливки действия.

Просчитано (WCAG 2.x, sRGB):

| Пара | Отношение | Вывод |
|---|---|---|
| киноварь `#D8382B` / сажа | **4,26:1** | ниже нормы — только графика и крупный текст |
| киноварь `#D8382B` / бумага | **3,98:1** | ниже нормы — на бумаге только `#B02A20` (5,63:1) |
| ярь `#2F9E82` / бумага | **2,84:1** | не годится — на бумаге только `#1A6150` (6,28:1) |
| крутик `#2B4C8C` / сажа | **2,37:1** | не годится — на тёмном только `#6B8FE0` (6,25:1) |
| киноварь 700 `#B02A20` / сажа | **3,01:1** | только заливка: на саже кнопке нужна светлая кайма |
| бумага `#F4EDDD` / сажа | 16,96:1 | ✓ |
| ярь светлая `#57D9B4` / сажа | 11,30:1 | ✓ |
| сусаль светлая `#E0A75C` / сажа | 8,05:1 | ✓ |
| киноварь светлая `#F2705C` / сажа | 6,83:1 | ✓ |
| крутик светлый `#6B8FE0` / сажа | 6,25:1 | ✓ |
| сусаль тёмная `#7A4E14` / бумага | 6,15:1 | ✓ |
| ярь тёмная `#1A6150` / бумага | 6,28:1 | ✓ |
| бумага на киновари 700 | 5,63:1 | ✓ текст кнопки в обеих темах |
| приглушённый `#635C4E` / бумага | 5,68:1 | ✓ |
| приглушённый `#635C4E` / поновление 100 | 4,87:1 | ✓ включая неактивную кнопку |

**Правила, которые из этого следуют:**

1. Средний тон пигмента не используется для мелкого текста ни на одном из фонов.
2. **Кнопка действия заливается киноварью 700, а не 500.** Пройти норму на 500 невозможно ни с бумагой (3,98:1), ни с сажей (4,26:1) — проходящей пары просто не существует.
3. **На саже кнопка получает светлую кайму.** Заливка 700 против фона даёт ровно 3,01:1, то есть граница на пределе; кайма киноварью светлой (6,83:1) делает её однозначной. В светлой теме кайма совпадает с заливкой: там разделять нечего.

Проверка — скриптом на сборке, скрипт печатает таблицу.

## 4. Типографика

| Роль | Шрифт | Где | Лицензия |
|---|---|---|---|
| Акциденция | **Fedorovsk Unicode** | h1–h3, буквица, заставки. Только короткие надписи, никогда абзацы | SIL OFL 1.1 |
| Модульный слой | **Handjet** (вариативный) | метки, надзаголовки, статусы, номера, вывод терминала | SIL OFL 1.1 |
| Текст | **Golos Text** | абзацы, интерфейс, кнопки | SIL OFL 1.1 |
| Код | **JetBrains Mono** | код, фрагменты CLI, идентификаторы, данные | SIL OFL 1.1 |

**Почему эта пара.** Fedorovsk воспроизводит набор Ивана Фёдорова XVI века — дониконовский книжный канон, то есть точную историческую привязку вместо очевидного Playfair. Handjet — вариативный модульный шрифт, у которого буква собирается из повторяющихся элементов. **Кириллица у Handjet есть, и это неочевидно: Press Start 2P, VT323 и Silkscreen кириллицу не поддерживают вовсе.**

**Оговорка по осям, проверенная на сборке.** У Handjet три оси: `wght`, `ELGR` (размер элемента) и `ELSH` (форма элемента). В файлах, которые отдаёт fontsource, есть **только `wght`** — осей `ELGR`/`ELSH` там нет, поэтому «квадратность» модульной метки опирается на начертание по умолчанию, а не на подведённую ось. Полный набор осей есть в исходной гарнитуре `github.com/rosettatype/handjet`; чтобы его получить, нужна своя сборка переменного шрифта. Пока это не сделано — так и написано, вместо обещания.

Шрифты **локальные**, woff2, `font-display: swap`, разбитые по кириллице и латинице через `unicode-range`. Никаких внешних CDN и ни одного внешнего запроса со страницы.

**Шкала:** `h1` clamp 32→56 · `h2` clamp 24→36 · `h3` clamp 18→23 · `lead` clamp 17→21 · `body` 17 · `sm` 15 · `caption` 14 · `mark` 13 (только модульные метки).
**Правила:** длина строки ≤ 66 знаков; смысловой текст не мельче 14px; Handjet — только метки и акценты; Fedorovsk — только акциденция; буквица (первая буква лида) — Fedorovsk крупно, киноварью.

**Мера набора задаётся в `em`, а не в `ch`.** `ch` — это ширина нуля того шрифта, который уже загрузился, а акциденция приходит с `font-display: swap`. Заголовок, ограниченный `22ch`, до загрузки Fedorovsk занимал 292px и стоял в три строки, после — 784px и одну: страница перескакивала на глазах. `em` привязан к кеглю и от момента загрузки шрифта не зависит. Для текстового слоя (`66ch` в `--measure`) это терпимо — там сдвиг не меняет число строк, — но для крупной акциденции недопустимо.

## 5. Пространство и сетка

Шаг 4px, модуль 8px, шкала `4 8 12 16 20 24 32 40 48 64 80 96`. Контейнер **1120px**, гатер 32px (20px на мобильном). Отступ секции 80px, на мобильном 48px. Сетка карточек: 3 → 2 → 1 колонка (переломы 960px и 640px).

## 6. Форма

Радиусы: `3 · 5 · 8 · 12 · 18 · 999`. Короткие, в ритме скругления модулей знака. Границы 1px `--border`; на карточку **одна** рамка. Тени только для приподнятых слоёв (модальные, выпадающие). В тёмной теме подъём передаётся светлее поверхностью, а не тенью.

**Свечение** (`--glow-accent`, `--glow-accent-2`) — только декоративные элементы: знак, рамка активной карточки, каретка терминала. Под смысловым текстом свечения нет. В светлой теме свечение отключено.

**Скан-линии** — фоновый слой секции hero, прозрачность ≤ 4%, шаг 3px. Никогда поверх текста.

## 7. Движение

`130ms` (наведение, фокус) · `220ms` (открытие, смена состояния) · `340ms` (модальные). Изинг `cubic-bezier(0.2, 0, 0, 1)`. При `prefers-reduced-motion: reduce` анимации гасятся полностью — правило обязательное.

| Компонент | Ключевые токены |
|---|---|
| Шапка | `--surface`, `--border`, `--z-header` |
| Hero | `--font-display`, `--fs-h1`, скан-линии фоном |
| Модульная метка | `--font-module`, `--fs-mark`, `--tracking-mark` |
| Блок установки | `--font-mono`, `--surface-2`, кнопка копирования |
| Карточка ядра | `--r-lg`, `--border`, одна рамка |
| Таблица «ядро и обвес» | `--font-mono` для имён модулей |
| Терминал | `--font-mono`, `--surface-2`, ярь для приглашения |
| Статус-пометка | `--font-module`, `--warn` или `--muted` |
| Кнопка `primary` | `--accent-fill` заливкой, `--on-accent` текстом, кайма `--accent-edge` |
| Кнопка `secondary` | рамка `--border-strong`, текст `--text` |
| FAQ аккордеон | `--fs-body`, `--border` |
| Футер | `--muted`, `--font-module` для подписей |

**Обязательные состояния каждого интерактивного элемента:** default · hover · focus-visible · active · disabled. Фокус — 2px `--focus-ring` с отступом 2px. Тап-зоны ≥ 44×44px.

## 9. Доступность

- Мелкий текст ≥ 4.5:1, крупный ≥ 3:1. Проверка скриптом на сборке.
- Фокус видимый на всех интерактивных элементах.
- Нет горизонтального скролла при 390px.
- Смысл не передаётся одним цветом: статусы — текстом, а не только цветом.
- Все изображения и иконки — с осмысленным `alt` и `role`.
- `prefers-reduced-motion` уважается.

## 10. Запреты

- ❌ Средний тон киновари или яри для мелкого текста.
- ❌ Больше двух акцентов на экран одновременно.
- ❌ Свечение или скан-линии под смысловым текстом.
- ❌ Handjet в абзацах; Fedorovsk в абзацах.
- ❌ Градиенты ради декора, тени на плоских элементах.
- ❌ Кегль < 14px для смыслового текста.
- ❌ Придуманные числа, статусы и вывод терминала.
- ❌ Церковнославянская лексика в описании продукта.
