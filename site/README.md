# Лендинг prokop — prokopii.ru

Статический одностраничный лендинг для ядра агента [`prokop`](https://github.com/yaugust939/prokop)
(Python, MIT). Живёт в ветке `site` того же репозитория, отдельной ветвью, чтобы не мешать `main`.

## Что здесь

```
site/
  design/
    tokens.css        источник истины по цвету и типографике
    tokens.json       те же токены машинно
    logo/             знак, локап, надпись, favicon
    fonts/            локальные woff2, без внешних CDN
  prototype/          исходники страницы
  tools/build-dist.mjs сборка в dist/
  deploy/             Dockerfile, nginx, compose, роут Traefik
  docs/
    01-design-system.md      принципы, палитра, шкала, компоненты, запреты
    02-logo-usage.md         правила логотипа
    03-value-proposition.md  ценностное предложение и копия страницы
  00_ТЗ.md            техзадание на сборку
  serve.py            локальный просмотр
```

## Сборка

```bash
node tools/build-dist.mjs      # prototype/ + design/ → dist/
python serve.py                # просмотр на http://127.0.0.1:8124
```

Минификации нет намеренно: файлы копируются и переписываются по глубине путей.

## Дизайн-система

Палитра названа по пигментам старопечатной книги и меднолитой иконы: сажа, поновление,
киноварь, ярь-медянка, сусаль, крутик, медь. Тона разведены на три ступени —
светлый для тёмного фона, основной для заливок, тёмный для мелкого текста на бумаге, —
потому что средние тона киновари и яри не проходят норму 4.5:1 ни на одном из фонов.

Шрифтовая пара: **Fedorovsk Unicode** (акциденция, набор Ивана Фёдорова XVI века)
и **Handjet** (модульный слой, вариативный, кириллица). Рабочий слой — **Golos Text**
и **JetBrains Mono**. Все четыре под SIL OFL 1.1, все локальные.

Знак «Ядро и обвес»: 12 модулей по кольцу и осмиконечный крест из тех же модулей в центре.
Косая перекладина — единственный элемент вне сетки, повёрнута на −19,3°.

## Требования

- Ноль внешних запросов со страницы: шрифты, стили и скрипты только локальные.
- Контраст мелкого текста не ниже 4.5:1, крупного не ниже 3:1.
- Нет горизонтального скролла при 390px.
- `prefers-reduced-motion` уважается.
- Никаких придуманных чисел, статусов и вывода терминала: всё либо из кода, либо с пометкой.

## Деплой

Контейнер `prokopii-site` на образе nginx, отладочный порт `127.0.0.1:8094`, роут Traefik
по файлу `deploy/traefik/prokopii.yml`. Соседние проекты (`/opt/aiartel`, порт 8093,
сеть `aiartel`) не затрагиваются.

Домен `prokopii.ru` требует A-записи на хост до публикации.
