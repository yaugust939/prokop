## 1. Что делаем

Статический одностраничный лендинг для ядра `prokop` (Python, MIT) на домен `prokopii.ru`.

Дизайн-система, логотип, палитра, шрифтовая пара и вся копия **уже написаны** и лежат в этой ветке. Задача сервера — **материализовать**: собрать шрифтовой конвейер, сверстать страницу по спецификации, написать сборщик и деплой-обвязку, провести фактчек утверждений по коду ядра и прогнать приёмку.

Творческих решений от сервера не требуется. Если спецификация где-то неоднозначна — сделать разумно, отметить в отчёте и **не расширять объём**.

### Fedorovsk Unicode — акцидентный шрифт

Воспроизводит набор Ивана Фёдорова XVI века. Источник — `github.com/slavonic/Fedorovsk`, файл `fonts/otf/Fedorovsk-Regular.otf`. Лицензия одиночная **SIL OFL 1.1** (`OFL.txt` кладётся рядом как `OFL-Fedorovsk.txt`).

*Уточнение по итогам первой сборки:* пакета `fonts-churchslavonic`, названного в прежней редакции этого ТЗ, не существует — ни репозиторием, ни в npm. Взят проект самой гарнитуры. Альтернатива на случай недоступности — `slavonic/node-church-slavonic-fonts` (npm `church-slavonic-fonts`), там лицензия двойная, GPLv3 **или** OFL 1.1; ветку OFL соблюдать обязательно и фиксировать это в `LICENSES.md`.

Отдаётся в OTF, нужен woff2. **`python3 -m pip` на сервере отсутствует, но `python3 -m ensurepip` ставит pip в venv** — это проверенный рабочий путь, и он даёт `pyftsubset`. Порядок попыток:

1. **`python3 -m ensurepip`** в изолированный venv → `pip install fonttools brotli` → `pyftsubset` по `unicode-range` из `tokens.css` с `--flavor=woff2`. Путь проверен первой сборкой. `apt-get` и `sudo` на сервере недоступны — не тратить на них время.
2. `npm i wawoff2` и конвертация через node.
3. Отдать OTF как есть, прописав в `tokens.css` формат `opentype` — но `tokens.css` менять нельзя, поэтому в этом случае **дописать рядом второй `@font-face` не нужно**: доложить в отчёт и перейти к пункту 4.
4. **Заменить акциденцию на Shafarik** — `shafarik@latest/cyrillic-400-normal.woff2` (Google Fonts, SIL OFL 1.1, кириллица и глаголица). Положить как `fedorovsk-cyrillic.woff2`, чтобы `tokens.css` не менялся, и **крупно отметить подмену в отчёте**.

**Проверка покрытия — обязательна.** Выбрать из собранного `index.html` все символы, реально встречающиеся в `h1`, `h2`, `h3`, и проверить, что они есть в таблице символов шрифта. Чего нет — в отчёт. Если акцидентный шрифт не покрывает современные русские буквы заголовков, идти по пункту 4.

## 4. Вёрстка

Одна страница `site/prototype/index.html`. Состав и порядок блоков — по `docs/03-value-proposition.md`, раздел «Копия страницы». Тексты брать **оттуда дословно**, не переписывать.

Правила, которые нельзя нарушить (полностью — в `docs/01-design-system.md`):

- Стили только через семантические роли из `tokens.css`. Никаких сырых hex в разметке и `app.css`.
- Подключение: `<link rel="icon">` → `tokens.css` → `assets/app.css`. Порядок как в семье.
- Тёмная тема по умолчанию: `<html lang="ru" data-theme="dark">`. Светлая — через `data-theme="light"`.
- Печать `@media print` — не нужна.
- **Ни одного внешнего запроса.** Ни CDN, ни счётчиков, ни `fetch`, ни аналитики. Шрифты только локальные. Проверяется грепом по `dist/`.
- Адаптив от 390px, горизонтального скролла нет. Переломы 960px и 640px.
- Обязательные состояния: hover, focus-visible, active, disabled у кнопок и ссылок.
- Тап-зоны не меньше 44×44px.
- Логотип — тегом `<img>` со `src="../design/logo/..."` (в `dist` сборщик перепишет путь), **не инлайновым SVG**: у файлов совпадают внутренние идентификаторы.
- Скан-линии в hero: `repeating-linear-gradient`, шаг 3px, прозрачность не выше 4%, только фоном.
- Свечение — только знак, рамка активной карточки, каретка терминала. Под смысловым текстом свечения нет.
- `prefers-reduced-motion: reduce` гасит всё — правило берётся из `tokens.css`, не дублировать.

Модульная метка (Handjet) — только для надзаголовков, статусов, номеров и имён модулей. Абзацы Handjet не набираются.

## 5. Сборщик `site/tools/build-dist.mjs`

Node ESM, запуск `node tools/build-dist.mjs`, копирует `prototype/` → `dist/`, кладёт дизайн-систему в корень сайта, переписывает пути по глубине, генерирует служебные файлы. Минификации нет — как принято в семье.

Обязательно:

1. Очистить `dist/`, скопировать `prototype/` целиком, исключая `serve.py` и `_backup`.
2. `design/fonts/` → `dist/fonts/`, `design/logo/` → `dist/logo/`, `design/tokens.css` → `dist/tokens.css`.
3. Переписать в `.html`, `.css`, `.js` по глубине: `../design/tokens.css` → `tokens.css`, `../design/logo/` → `logo/`, `../assets/` → `assets/`.
4. Сгенерировать `dist/robots.txt` со `Sitemap: https://prokopii.ru/sitemap.xml`.
5. Сгенерировать `dist/sitemap.xml` обходом `dist/` по `*.html`, исключая `404.html`.
6. Сгенерировать `dist/404.html` и `dist/healthz` со содержимым `ok`.
7. В конце — скан `dist/` на остатки `../design/` и печать первых нарушителей.
8. `const SITE = 'https://prokopii.ru'` — **одна константа**, чтобы домен не разъехался по файлам.

В `<head>`: `charset`, `viewport`, `title`, `description`, `canonical` на `https://prokopii.ru/`, `og:type`, `og:url`, `og:title`, `og:description`, `og:site_name` = `prokop`, `og:locale` = `ru_RU`, иконка `favicon.svg`.

## 6. Деплой-обвязка

Кладётся в `site/deploy/`. **Сервер её только пишет, разворачивает локальная сторона.**

`Dockerfile` — многостадийная сборка, чтобы `dist/` не попадал в git и файлы не перетаскивались руками:

```dockerfile
FROM node:24-alpine AS build
RUN apk add --no-cache git
ARG SITE_REF=site
ARG SITE_REV
RUN test -n "$SITE_REV" || exit 1
RUN git clone --branch "$SITE_REF" https://github.com/yaugust939/prokop /src \
 && git -C /src checkout --detach "$SITE_REV" \
 && test "$(git -C /src rev-parse HEAD)" = "$SITE_REV"
WORKDIR /src/site
RUN node tools/build-dist.mjs

FROM nginx:1.27-alpine
RUN apk add --no-cache tzdata && cp /usr/share/zoneinfo/Europe/Moscow /etc/localtime
COPY nginx.conf /etc/nginx/conf.d/default.conf
COPY security-headers.conf /etc/nginx/snippets/security-headers.conf
COPY --from=build /src/site/dist/ /usr/share/nginx/html/
EXPOSE 80
HEALTHCHECK CMD wget -q -O /dev/null http://127.0.0.1/healthz || exit 1
CMD ["nginx", "-g", "daemon off;"]
```

**Ревизия обязательна, и это не формальность.** Docker кэширует слой по тексту инструкции, а результат сетевой операции в ключ кэша не входит: без меняющегося аргумента пересборка молча берёт клон из кэша и везёт в образ старый код. **На это уже наступили:** вторая сборка «прошла» со старым сборщиком и упала только потому, что тот был сломан. Клон поэтому полный, а не `--depth 1` — так выкатка возможна на любой коммит, а не только на вершину ветки. Вызов:

```
SITE_REV=$(git ls-remote https://github.com/yaugust939/prokop refs/heads/site | cut -f1) \
  docker compose up -d --build
```

`nginx.conf` — по образцу семьи, `server_name _`, слушает 80: `charset utf-8`, `server_tokens off`, gzip с `font/woff2`, заголовки безопасности, `location = /healthz` отдаёт `ok`, статика с `Cache-Control: public, max-age=2592000`, `/fonts/` на 180 дней, `/` с `must-revalidate` и чистыми URL через `try_files $uri $uri.html $uri/index.html $uri/ =404`, `error_page 404 /404.html`, запрет точек кроме `/.well-known`.

`docker-compose.yml` — сервис `prokopii-site`, образ `prokopii-site:latest`, `container_name: prokopii-site`, `restart: unless-stopped`, **отладочный порт строго `127.0.0.1:8094:80`** (8093 занят артелью, 8095 и 8096 тоже заняты), внешняя сеть `traefik-net`.

`traefik/prokopii.yml` — по образцу `neuro-artel.yml`, но **свой файл**, `neuro-artel.yml` не трогать: два роутера на `web` и `websecure` с `rule: Host(\`prokopii.ru\`)`, `tls.certResolver: letsencrypt`, сервис с бэкендом **по имени контейнера** `http://prokopii-site:80` (не `127.0.0.1` — это давало 502), `healthCheck.path: /healthz`.

## 8. Приёмка — прогнать и показать результат

1. **Ноль внешних запросов.** Греп по `dist/**/*.{html,css,js}` на `http://`, `https://`, `//cdn`, `@import`. Допустимы только: `https://prokopii.ru` в canonical, og и sitemap, `https://github.com/yaugust939/prokop` в ссылках, `http://www.w3.org/2000/svg` в `xmlns` у SVG. Всё остальное — нарушение, показать список.
2. **Контрасты.** Скрипт считает WCAG 2.x для всех пар «текст/фон», реально встречающихся в `app.css`, и печатает таблицу. Все пары мелкого текста ≥ 4.5:1, крупного ≥ 3:1. Нарушения — в отчёт.
3. **Нет горизонтального скролла при 390px.** Проверить расчётом ширин в `app.css`: ни одного `width`, `min-width` и `padding`, дающего переполнение при 390px без медиазапроса.
4. `dist/` содержит `index.html`, `404.html`, `robots.txt`, `sitemap.xml`, `healthz`, `tokens.css`, `fonts/`, `logo/`, `assets/`.
5. `node tools/build-dist.mjs` проходит без ошибок и печатает число файлов.
6. Все `@font-face` из `tokens.css` находят свой файл в `dist/fonts/`. Печатать таблицу «объявлено → файл есть/нет».
7. `dist/index.html` — валидный HTML: без незакрытых тегов, `alt` у всех `<img>`, `<html lang="ru">`.
8. **Сборка обязана проходить без python.** В образе `node:24-alpine` python нет, поэтому сборщик там идёт по ветке «pytest недоступен → `tools/test-count.json`». Эту ветку нужно проверять отдельно: `PATH` без python, `PROKOP_TESTS` не задан, `node tools/build-dist.mjs` обязан завершиться кодом 0 и подставить число из записи. Ветка «pytest доступен» проверяется обычным прогоном. **Первая сборка эту проверку пропустила: на сервере pytest был доступен, функция выходила раньше сломанной ветки, и падение вылезло только в Docker (`JSON.parse` от необработанного `readFile`).** Проверять обе ветки, а не ту, что под рукой.
9. **Живой рендер — обязателен, и без браузера он не делается.** Проверки 1–8 статические; они не видят, как страница выглядит и как ведёт себя при загрузке шрифтов. Смотреть в браузере, минимум:
   - **меры наборов не должны зависеть от шрифта.** `ch` считается от нуля *фактического* шрифта, а акциденция приходит с `font-display: swap`. Заголовок был ограничен `max-width: 22ch`: до загрузки Fedorovsk это давало 292px и три строки, после — 784px и одну. Страница перескакивала на глазах. Лечится `em`, который зависит от кегля, а не от того, какой шрифт успел загрузиться. Проверка: измерить блок до и после `document.fonts.ready` — размеры и число строк обязаны совпасть;
   - заголовок ломается по фразам, а не оставляет одно слово на строке;
   - оба шрифта акциденции и модульный слой действительно отрисовались, а не подменились fallback-стеком (`document.fonts.check`);
   - при 390px нет горизонтального скролла и ни один блок не шире экрана.
   **Этот пункт появился из живого дефекта:** статическая приёмка первую сборку пропустила, а браузер нашёл сразу.
